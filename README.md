# 🎁 크리스마스 선물이 도착했습니다

> 심사를 통과한 친구만 받을 수 있는 크리스마스 선물 사이트 🎄

![썸네일](site/assets/og.png)

**👉 [yeaji-christmas.netlify.app](https://yeaji-christmas.netlify.app)**

<br>

## 🎄 어떻게 진행되나요?

1. **별명 입력**: 선물을 받을 친구의 별명을 적고 입장해요.
2. **출입 심사**: 몇 가지 질문에 **모두 "예"** 해야 통과할 수 있어요.
   "아니오"를 누르면… 🚫 관계자 외 출입 금지
3. **트리 재료 시험**: 퀴즈 5문제의 답이 그대로 트리의 재료가 돼요.
4. **나만의 트리 공개**: 결과에 따라 서로 다른 트리를 받아요.
5. **선물 열기**: 트리 밑 선물 상자를 열어보세요. 🤫

<br>

## 🌲 받을 수 있는 트리

| 트리 | 조건 |
|---|---|
| ✨ **반짝반짝 완벽한 트리** | 전부 정답! 곰돌이와 선물 더미까지 |
| 🐶 **망꼬 트리** | 망꼬 문제를 틀리면… 망꼬로 뒤덮인 트리 |
| 🐸 **슬픈 트리** | 나에 대한 문제를 틀리면… 트리도 울어요 |
| 🐟 **붕어빵 트리** | 팥붕파에게는 붕어빵 트리를 드립니다 |

<br>

## 🛠 환경 구성

| 구분 | 내용 |
|---|---|
| 환경 구성 | Vanilla JS (빌드 도구 없이 HTML, CSS, JS만 사용) |
| 그래픽 | SVG (트리·소품), Canvas (망꼬 픽셀아트, 눈·폭죽 파티클) |
| 폰트 | Google Fonts (Gaegu, Jua) |
| 서버 | 없음. 정적 사이트, 상태는 메모리에만 저장 |
| 인프라 | Netlify Drop (`site/` 폴더만 업로드해서 배포) |

```
christmas-gift/
├─ site/          # 🌐 배포되는 사이트
│  ├─ index.html
│  ├─ css/
│  ├─ js/         # config.js에서 질문·정답·멘트 수정
│  └─ assets/
└─ docs/SPEC.md   # 서비스 흐름·스펙
```

<br>

## ▶️ 로컬에서 실행

```bash
npx serve site
```
